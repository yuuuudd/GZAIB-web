# 生产环境账号认证设计

## 目标

在 `gzaibuilders.cn` 上运行现有 Vinext 应用，让每位访客都能自主注册账号，会员和管理员共用一套登录流程，不依赖 ChatGPT Sites 注入的身份请求头。同时保留现有 ChatGPT Sites 身份认证路径，使原托管站点继续可用。

## 当前约束

- 应用使用 Vinext/Vite，并依赖兼容 Cloudflare 的 D1、R2 绑定。
- 腾讯云服务器将使用 Cloudflare Vite 插件提供的本地持久化 D1/R2 运行时，并非远端 Cloudflare D1/R2。
- 数据库已经有 `users` 和 `sessions` 表；当前生产认证只信任 ChatGPT Sites 提供的 `oai-authenticated-user-*` 请求头。
- 在取得微信开放平台已审核网站应用的 AppID 和 AppSecret 前，不能启用微信网站扫码登录。
- 正式环境必须关闭 Demo 身份和公开的身份切换器。

## 账号流程

新增 `/register`、`/login` 页面及对应的 POST 接口。注册时接收规范化后的邮箱和密码，创建持久化会员账号及一条密码凭证，随后建立服务端会话。登录验证密码后建立相同类型的会话。退出登录时先撤销数据库中的会话，再清除 Cookie。

第一版将邮箱作为账号标识。由于尚未配置邮件服务，本版本不宣称邮箱已经验证，也不提供自动找回密码。用户资料和公开会员资格仍须经过应用现有的管理员审核流程。

用户 ID 使用随机、与登录提供方无关的值。以后接入微信时，可将微信身份绑定到现有用户，不必更换资料、连接或审核记录的所属账号。

## 密码与会话安全

新增以 `user_id` 为主键的 `password_credentials` 表。只保存随机盐、PBKDF2-HMAC-SHA-256 计算结果、迭代次数和更新时间，不保存明文或可逆密码。使用 Web Crypto，确保实现同时兼容 Cloudflare 运行时和 Node。密码长度限制为 12～128 个 Unicode 字符，校验结果使用恒定时间比较。

会话使用随机且不可推测的 `gzaib_session` Cookie；设置 `HttpOnly`、生产环境 `Secure`、`SameSite=Lax` 和 `Path=/`。现有 `sessions` 表只保存令牌的 SHA-256 哈希。会话有效期为 30 天；每次认证请求都重新检查账号状态；退出登录或注销账号时撤销会话。

所有认证响应使用私有且禁止缓存的响应头。登录失败统一返回同一提示。注册遇到重复邮箱时不泄露额外账号信息。限制请求正文大小，并对注册、登录实施基于 IP 的进程内限速。限速器只覆盖单个 PM2 进程，因此生产环境仅运行一个应用实例；以后需要多实例时再升级为共享限速存储。

## 统一身份边界

扩展现有 `resolveRequestUserId` 身份边界，按以下顺序判断：

1. 仅当 `DEMO_MODE=true` 时读取签名 Demo 会话。
2. 读取有效的数据库 `gzaib_session` 会话。
3. 在 ChatGPT Sites 托管环境中存在可信身份请求头时，读取 ChatGPT Sites 身份。
4. 其余情况视为未登录访客。

Nginx 转发请求前必须清除所有外部传入的 `oai-authenticated-user-*` 请求头，避免公网访客伪造 ChatGPT 用户身份。

未登录访客访问账号页面时跳转到 `/login?return_to=...`。现有 API 保持原有的 `401` 响应约定。

## 管理员流程

管理员和普通用户共用 `/login` 页面，登录后直接访问 `/admin`。管理员权限来自数据库中持久化的 `users.role`，不依赖邮箱请求头，也不另设 Nginx 管理密码。

网站对公网开放前，先让首个账号通过只监听 localhost 的正常注册流程创建，再使用一次性本地 D1 语句将这个准确账号提升为 `admin`。公开注册接口始终只创建 `member`，任何注册请求都不能自行指定 `admin`。

所有 `/admin` 页面和 `/api/admin/*` 接口都必须解析数据库会话，并确认账号状态有效且 `role=admin`。现有审计日志机制保持不变。

## 数据库迁移

在现有迁移之后新增一个连续编号的迁移，仅创建 `password_credentials` 表及其到 `users` 的外键，不引入无关结构。已有用户和 ChatGPT 托管账号继续有效。

## 用户界面

沿用现有视觉语言，新增紧凑的登录和注册卡片，包括邮箱、密码、提交按钮、登录/注册链接、可访问性标签、键盘焦点和通用错误反馈。在非 Sites 环境中，将账号页面原有的 ChatGPT 专属登录跳转替换为本地登录地址。没有真正可用的社交登录前，不展示占位按钮。

## 后续微信登录

微信网站应用审核通过后，增加使用 `snsapi_login` 的 OAuth2 授权码登录、服务端 state 校验，以及微信身份到现有用户的映射。已有用户必须在登录状态下主动绑定微信，禁止仅凭未验证邮箱自动合并账号。AppSecret 只保存在服务器端。

## 生产部署

- 使用 Node.js 24 LTS，通过 `npm ci` 安装依赖，并依次执行单元测试、代码检查和 `vinext build`。
- 将全部连续编号的 D1 迁移按顺序应用到服务器本地持久化状态。
- 使用 PM2 运行单个 Vinext 生产进程并配置开机自启。
- Nginx 反向代理到应用实际监听的 localhost 端口，清除可伪造的身份请求头，并正确传递主机名和协议请求头。
- 域名解析前先通过 localhost 和服务器公网 IP 验证应用与认证流程。
- `gzaibuilders.cn` 解析到服务器后启用 TLS，并在 HTTPS 环境验证 Secure Cookie 登录。

## 验证要求

- 密码测试覆盖正确密码、错误密码、非法输入及长度边界。
- 注册测试覆盖邮箱规范化、重复邮箱、强制会员角色、请求大小限制和会话创建。
- 登录与会话测试覆盖通用失败提示、令牌哈希、过期、撤销、非活跃账号和 Cookie 属性。
- 管理员测试证明普通会员不能访问管理页面或接口，持久化管理员会话可以访问。
- 现有单元测试、代码检查、构建和服务端渲染检查全部通过。
- 生产冒烟测试覆盖首页、注册、登录、`/me`、普通会员访问 `/admin` 被拒、管理员访问、退出登录、PM2、Nginx 和监听端口。

## 明确暂缓

- 微信扫码登录：等待 AppID、AppSecret 和审核通过的回调域名。
- 邮箱验证与自动找回密码：等待配置邮件服务。
- 远端 Cloudflare D1/R2：当前腾讯云服务器使用本地持久化绑定。
