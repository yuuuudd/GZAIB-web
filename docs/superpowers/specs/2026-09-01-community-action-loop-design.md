# 社群共创闭环首页框架设计

## 目标

将首页现有的“一束光如何亮起”四步审核说明，替换为能表达广州 AI 共创社核心价值的共创闭环。本轮只搭建首页信息与视觉框架，不建设项目管理、报名或协作后台。

## 已确认文案

- 主标题：`从连接，到创造`
- 副标题：`让议题找到同行，让行动沉淀成果。`
- 五个节点：`发现 → 连接 → 共创 → 落地 → 沉淀 ↺`

## 节点含义

1. **发现**：发现议题、活动、社群与真实需求。
2. **连接**：通过共建地图与公开档案找到同行者。
3. **共创**：加入共建网络，发起安全的双向连接。
4. **落地**：通过活动、组队与协作把想法变成行动。
5. **沉淀**：将作品、经验和贡献留在公开档案中，进入下一轮发现。

## 交互与链接

- 节点应当是可理解的过程说明，不伪装尚未存在的平台能力。
- 可复用现有入口时，链接到活动赛事、AI 社群、共建地图和申请加入。
- “落地”与“沉淀”首期只表达社群方法，不链接到不存在的项目中心。

## 视觉与响应式

- 复用现有蓝色、橙色、圆形节点与白色容器，不引入新设计系统。
- 桌面端保持横向五步流程，用回环提示“沉淀”返回“发现”。
- 移动端改为纵向阅读，节点顺序与语义保持不变。
- 循环关系不只依赖颜色，同时使用文字和箭头表达。

## 验收标准

1. 首页不再把该区域表达为单向审核流程。
2. 五个两字节点、主副标题和闭环关系准确呈现。
3. 现有共建地图、社群、活动和申请入口不受影响。
4. 桌面端与移动端无横向溢出，阅读顺序正确。
5. 不新增数据库表、API、项目管理页或新依赖。
