# 轻量化共建地图设计说明

## 目标

把当前接近原生高德地图的目录页改造成“共建网络地图”：默认聚焦广州，向外缩放后进入广东城市总览；地图表达成员、学校和城市之间的关系，不展示道路、商业 POI、建筑等无关信息。

## 已确认的交互

- 默认进入广州学校层，地图居中广州，即使当前没有成员也能显示。
- 广州学校层不显示行政区色块，只显示广州城市外轮廓、学校图钉和必要的水陆背景。
- 学校图钉使用生动的水滴形品牌图钉，尖端精确落在学校坐标上；图钉内部显示“成员数”，外侧显示学校全名。
- 选中的学校图钉变为橙色，其余为蓝色，并打开现有学校成员抽屉。
- 缩小到省级尺度时进入广东总览，显示城市边界；每个有数据的城市显示成员总数与学校数。
- 点击城市后进入该城市学校层，显示这个城市的学校图钉。
- 页面保留“广东 / 当前城市”层级导航，用户不必依赖滚轮即可切换层级。
- 所有统计使用当前筛选结果，因此学校、专业、技能等筛选会同步改变城市和学校计数。
- 移动端地图占满内容宽度，学校详情使用底部抽屉。
- 地图脚本或边界服务失败时，不显示大块错误墙，而显示可操作的两级目录：先选城市，再选学校。

## 地图技术方案

高德 JS API 2.0 继续负责坐标投影、缩放和平移。地图底图只保留背景层并隐藏标签，避免道路与 POI 干扰。行政边界通过高德行政区能力获取：省级展示广东及地级市边界；城市学校层只绘制当前城市外轮廓，不绘制广州各区色块。

学校搜索得到的 POI 一般只有名称、地址和中心坐标，并不保证提供校区真实边界。因此本期以精确坐标图钉呈现学校，不伪造校区轮廓。后续若管理员录入或上传可靠的校区边界，可以在不改变数据聚合逻辑的情况下增加可选轮廓层。

## 数据模型

不新增数据库字段。目录接口已有的学校数据包含学校名、校区、城市、经纬度、成员数及预览成员。本功能在前端派生城市聚合：

- `city`: 规范化城市名称
- `memberCount`: 当前筛选结果中该城市的成员数总和
- `schoolCount`: 当前筛选结果中该城市的学校数
- `center`: 由有坐标学校加权计算的城市视觉中心；没有数据时使用广东主要城市默认中心
- `schools`: 属于该城市的学校列表

## 状态与切换

页面维护 `province | city` 两种语义层级，以及当前城市和当前学校。缩放结束时根据阈值切换层级；点击城市或面包屑也可以显式切换。程序设置缩放时使用短暂锁，避免一次操作触发相反的自动切换。

筛选结果变化后重新计算聚合。如果当前城市已经不在结果中，仍保留城市视图并显示空状态，避免地图突然跳走。

## 视觉规范

- 背景使用现有页面的浅蓝灰色系。
- 城市边界用低对比度蓝灰描边；省级选中城市可使用极浅的半透明品牌蓝，不形成厚重色块。
- 学校图钉为品牌蓝，圆形主体内以白字显示人数；尖角作为地理锚点。
- 图钉外侧学校全名使用白底轻阴影标签，避免与边界线混在一起。
- 选中态使用暖橙色，形成唯一高强调点。
- 聚合信息优先使用中文短标签，如“18 位共建者 · 4 所学校”。

## 无数据与降级

地图无成员时仍显示广州底图、城市轮廓和“当前筛选暂无学校”的轻量提示。高德脚本失败、鉴权失败或边界服务不可用时，页面切换为城市/学校两级目录；重试按钮作为辅助操作，不阻断浏览。

## 验收标准

1. 首屏看到广州地图而非广东全省或错误占位。
2. 广州层没有区级色块，道路、POI、建筑标签不可见。
3. 学校图钉内部为人数，外侧为全名，点击可打开学校详情。
4. 缩小后看到广东城市边界与城市汇总，点击城市能进入学校层。
5. 筛选后城市和学校数字同步更新。
6. 没有成员时地图仍存在；地图加载失败时可用两级目录浏览。
7. 桌面和手机布局均可操作，构建与自动测试通过。
